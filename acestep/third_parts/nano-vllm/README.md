# Nano-vLLM

Bundled lightweight inference backend for the ACE-Step 5Hz language model.

Upstream: [GeeeekExplorer/nano-vllm](https://github.com/GeeeekExplorer/nano-vllm). This distribution retains the runtime source and its [MIT license](LICENSE). Install via the root project's `uv sync` or, in an appropriate PyTorch environment, `pip install -e acestep/third_parts/nano-vllm` from the repository root.
